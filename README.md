## Practical experience

At Metso, my work has included developing an integration tool between engineering software and a database using .NET 8 and GitHub Copilot. One feature I implemented detects changes in the other application and requires the user to review them before saving, helping prevent accidental overwrites and loss of information.

This work has given me experience modifying an existing application, debugging, iterating and solving problems in an industrial setting.

## Selected projects

### 🏎️ [LPR Lap Challenge](https://github.com/panulut/lprmotorsport)

A browser racing game inspired by Formula Student. My development work includes driving gameplay, a track editor, lap timing and leaderboards, alongside performance improvements and testing.

### 🔧 [Formula Student CAN Simulator](https://github.com/panulut/FSLUT-ESP32-CAN-Bus-Mock)

A CAN bus simulation tool for the LUT Formula Student team, built around an ESP32 and MCP2515 controller. The project includes configurable message transmission, recording replay, serial commands and a browser demo for testing without hardware. Hardware validation is still in progress.
